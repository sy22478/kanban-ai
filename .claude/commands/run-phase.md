Use the `run-phase` skill for phase $ARGUMENTS.

Follow it as written. In particular: plan first and wait for approval before doing any work, batch
your questions rather than asking them one at a time, and stop rather than guess when a decision
is mine to make.

This command exists so the skill is invoked deliberately rather than left to match on its own
description.
